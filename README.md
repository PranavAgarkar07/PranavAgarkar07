### `// ==== PROJECTS ====`

```text
pranav@dev:~$ ls -la projects/
```

> **[BeamSync](https://github.com/PranavAgarkar07/BeamSync)** — peer-to-peer file transfer over your local network, built with Go + Svelte. No cloud, no accounts, no upload limits — my hostel friends use it to share projects, movies, and thousands of trip pics.

> **[TaskVault Lite](https://github.com/PranavAgarkar07/taskvault-lite)** — full-stack task manager (Django REST + React) with JWT/OAuth auth and Fernet-encrypted data. Most todo apps sell your data or shove ads in your face — this one just works.

> **[Portfolio](https://github.com/PranavAgarkar07/portfolio-svelte)** — Svelte 5 + SvelteKit site with a custom aerospace-brutalist design, live GitHub activity feed, and an encrypted contact form. A spot on the web that actually feels like me.
